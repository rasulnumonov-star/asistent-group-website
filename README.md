# Asistent Group — сайт

Одностраничный сайт-визитка Asistent Group: автоматизация для образования, общепита и производства в Узбекистане. Хайтек-дизайн, переключение языка RU/UZ, адаптивная вёрстка.

## Стек

- Статический HTML + Tailwind CSS (через CDN) + vanilla JS
- `serve` — минимальный Node-сервер для продакшена (нужен для деплоя на Railway)

## Структура

```
index.html      — весь сайт (разметка, стили, скрипты в одном файле)
assets/         — исходники логотипа (PNG), в сам сайт логотип встроен как base64
package.json    — зависимости и команда запуска
railway.json    — конфиг деплоя для Railway
```

## Запуск локально

```bash
npm install
npm start
```

Сайт откроется на `http://localhost:3000`.

## Деплой на Railway

Проект подключён к Railway через сборщик Nixpacks: при пуше в GitHub Railway автоматически ставит зависимости (`npm install`) и запускает `npm start`. Порт берётся из переменной окружения `PORT`, которую Railway задаёт сама.
